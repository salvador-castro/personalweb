## Visión general

**CRUDMoviesPHP** es una aplicación web ligera y moderna para gestionar tus películas y series favoritas. Podés cargar títulos, editarlos, filtrarlos fácilmente y exportarlos a PDF. Está pensada para ser simple de usar, visualmente clara y adaptable a todo tipo de dispositivos.

## Funcionalidades principales

- **Gestión de contenido**: Alta, baja y modificación de películas y series.
- **Filtros dinámicos**: Por título, género, tipo (película o serie) y estado.
- **Modo oscuro**: Cambio de tema incorporado con un solo clic.
- **Exportación a PDF**: Descargá tu catálogo con formato profesional.
- **Interfaz responsiva**: Diseño moderno con Bootstrap 5.

## Tecnologías utilizadas

🎨 **Front-end:** HTML5, CSS3, Bootstrap 5, JavaScript  
⚙️ **Back-end:** PHP 8.x  
🗄️ **Base de datos:** MySQL  
📄 **Exportación:** DomPDF  
🌙 **Tema UI:** Tema propio con modo oscuro

## Desafíos y aprendizajes

Uno de los principales desafíos fue construir una arquitectura limpia sin frameworks, manteniendo la organización del código y la escalabilidad. También fue clave trabajar la experiencia de usuario al aplicar filtros dinámicos y al generar el PDF, asegurando un diseño consistente.

Este proyecto me permitió profundizar en el uso de PHP puro, modularizar funciones y reforzar buenas prácticas de desarrollo sin depender de grandes librerías.

## Resultado

La aplicación es rápida, liviana y fácilmente adaptable a nuevas funcionalidades. Representa una excelente base para otros proyectos CRUD o como práctica para desarrolladores que quieran afianzar sus conocimientos en PHP y MySQL.
