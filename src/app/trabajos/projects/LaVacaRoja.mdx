## Visión general

La Vaca Roja es una plataforma fullstack para una carnicería con más de 20 años de trayectoria en Palermo, Buenos Aires. La solución integra una tienda online para clientes con catálogo de cortes premium, carrito de compras y pagos online, junto con un panel de administración completo para la gestión interna del negocio.

## Funcionalidades principales

### Tienda (Frontend — React + Vite)

- **Hero con estadísticas** del negocio: 20+ años, 15k clientes, 60+ cortes y rating de 4.9★.
- **Catálogo de productos** con filtros por categoría y búsqueda en tiempo real, cargado desde Supabase.
- **Promociones destacadas** (combos) con badges dinámicos (OFERTA / NUEVO / PREMIUM).
- **Descuentos bancarios** con cards visuales por banco (Cuenta DNI, BBVA, Ualá).
- **Carrito lateral** (CartDrawer) con gestión de cantidades y persistencia de sesión.
- **Checkout con Mercado Pago** — páginas de resultado para pago exitoso, pendiente y fallido.
- **Autenticación** con registro, login y reset de contraseña vía Supabase Auth.
- **Dashboard privado** para clientes autenticados.
- **Exportación de reportes** en PDF (jsPDF) y Excel (xlsx).
- **Diseño responsive** con scroll reveal animations y microanimaciones.

### Panel de Administración (Backend — Next.js + Tailwind CSS v4)

- **Dashboard con métricas** y gráficos (ApexCharts) con datos en tiempo real desde Supabase.
- **Gestión de productos** — alta, edición, baja, upload de imágenes.
- **Gestión de pedidos** con estados y seguimiento.
- **Calendario de eventos** con FullCalendar (vistas por día, semana, mes y lista).
- **Mapa de distribución** de clientes con react-jvectormap.
- **Drag & Drop** para reordenamiento de elementos (react-dnd).
- **Autenticación SSR** con `@supabase/ssr` y middleware de protección de rutas.
- **Dark mode** nativo.

## Tecnologías utilizadas

### Frontend

- ⚛️ **React** (v19) + **Vite**
- 🗃️ **Supabase** (Base de datos, Storage y Auth)
- 🛣️ **React Router DOM** (v7)
- 💳 **Mercado Pago** (pagos online)
- 📄 **jsPDF + jspdf-autotable** (exportación PDF)
- 📊 **xlsx** (exportación Excel)
- 🎨 **CSS personalizado** (sistema de diseño propio)

### Backend / Admin

- ▲ **Next.js** (v16) con App Router
- 🗃️ **Supabase** (`@supabase/ssr`)
- 🎨 **Tailwind CSS** (v4)
- 📅 **FullCalendar** (v6)
- 📊 **ApexCharts** para React
- 🗺️ **react-jvectormap**
- 🖱️ **react-dnd** (Drag & Drop)

## Resultado

Una solución fullstack completa que digitaliza el negocio de La Vaca Roja: desde la experiencia de compra del cliente hasta la operación interna del local. La arquitectura desacoplada (frontend en Vite + backend en Next.js) permite escalar y mantener cada capa de forma independiente.
